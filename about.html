ที่มาและวัตถุประสงค์

พจนานุกรมภาษาถิ่นไทยนี้เป็นโครงงานคอมพิวเตอร์ระดับมัธยมศึกษาตอนปลาย จัดทำขึ้นเพื่อแก้ปัญหาความยากในการค้นหาและเปรียบเทียบคำภาษาถิ่นของไทย ทั้ง 4 ภาค (กลาง เหนือ อีสาน ใต้) โดยรวบรวมคำภาษากลางและคำภาษาถิ่น ไว้ในฐานข้อมูลกลางเดียวกัน พร้อมระบบค้นหาและกรองตามภาค เพื่อให้ครูและนักเรียนใช้ค้นคว้าและศึกษาความหลากหลายทางภาษาได้สะดวก โดยเฉพาะการใช้งานผ่านโทรศัพท์มือถือ

จัดทำโดย: (ใส่ชื่อโรงเรียนและรายชื่อสมาชิกกลุ่มของคุณที่นี่)

วิธีเก็บข้อมูล

ข้อมูลคำศัพท์ทั้งหมดถูกจัดเก็บในรูปแบบตาราง (Google Sheets) แล้วเผยแพร่ เป็นไฟล์ CSV ให้เว็บไซต์ดึงไปแสดงผลแบบเรียลไทม์ผ่านไลบรารี PapaParse โดยแต่ละคำมีข้อมูลครบทั้งคำภาษากลาง คำภาษาถิ่น ภาคและจังหวัดที่ใช้ คำอ่าน ชนิดของคำ ระดับภาษา ความหมาย ตัวอย่างประโยค และหมายเหตุทางภาษาศาสตร์

คำที่ถูกเสนอเข้ามาใหม่ (ผ่านหน้า “เสนอคำใหม่”) จะถูกทำเครื่องหมายสถานะ “รอตรวจ” ก่อนเสมอ จากนั้นทีมงานจะตรวจสอบความถูกต้องร่วมกับเจ้าของภาษา ในแต่ละภูมิภาค เมื่อยืนยันแล้วจึงเปลี่ยนสถานะเป็น “ยืนยัน” และแสดงผล ในหน้าค้นหาและหน้าคำทั้งหมด

คอลัมน์ความหมาย
centralคำภาษากลาง
dialectคำภาษาถิ่น
region / provinceภาคและจังหวัดที่ใช้
readingคำอ่านออกเสียง
meaning / exampleความหมายและตัวอย่างประโยค
statusสถานะตรวจสอบ (ยืนยัน / รอตรวจ)

แหล่งอ้างอิงและเครื่องมือที่ใช้

  • Google Sheets — จัดเก็บและแก้ไขฐานข้อมูลคำศัพท์
  • PapaParse (papaparse.min.js) — แปลงไฟล์ CSV เป็นข้อมูล JavaScript
  • GitHub Pages — โฮสต์เว็บไซต์แบบไม่มีค่าใช้จ่าย
  • Google Fonts (Noto Sans Thai) — ฟอนต์แสดงผลภาษาไทย

(เพิ่มแหล่งอ้างอิงทางวิชาการหรือผู้ให้ข้อมูลภาษาถิ่นที่ใช้จริงตรงนี้)
